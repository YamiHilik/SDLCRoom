## 2. Состояния интерфейса

<!-- Для каждого экрана или компонента описать все возможные состояния. -->

### 2.1 [Название экрана] — состояния

#### Загрузка (`loading`)

> Что видит пользователь, пока данные загружаются.

- Индикатор: спиннер / скелетон / прогресс-бар
- Заблокированные элементы: кнопки, поля ввода
- Таймаут: через N секунд переход в состояние `error`

#### Успех (`success`)

> Штатный вид экрана с полными данными.

- Отображаемые данные: …
- Доступные действия: …

#### Пустой список (`empty`)

> Экран без данных — первый запуск или результат фильтрации.

- Иллюстрация / иконка: …
- Текст: «[Сообщение для пользователя]»
- Призыв к действию: кнопка «[Добавить / Начать / …]»

#### Ошибка (`error`)

> Сбой загрузки данных или операции.

- Текст ошибки: «[Человекочитаемое сообщение]»
- Техническая деталь: скрыта / свёрнута под спойлер
- Действие: кнопка «Повторить» / ссылка на поддержку

#### Офлайн (`offline`) *(если применимо)*

> Нет сети или соединения с сервером.

- Индикатор: баннер / иконка
- Деградированный режим: что доступно без сети
